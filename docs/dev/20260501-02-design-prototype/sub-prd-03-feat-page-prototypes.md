# SUB-PRD: `페이지 프로토타입`

## 작업 정보

- **작업명**: `페이지 프로토타입`
- **작업 유형**: `feat` (새로운 기능 추가)
- **시작일**: 2026-05-01
- **종료일**: 2026-05-02
- **최신 업데이트**: 2026-05-02
- **상태**: 완료

## 배경 및 목적

Sub-01(토큰)과 Sub-02(컴포넌트)에서 구현한 요소를 조합하여, Dopamine Planner 서비스의 **7개 전체 페이지 레이아웃**을 430px 모바일 프레임으로 구현한다. 실제 개발 전에 화면 흐름과 레이아웃을 확정하기 위한 시각적 검증 목적이다.

## 기술 스택

| 영역 | 기술 |
|------|------|
| 마크업 | HTML5 (Sub-01의 index.html 확장) |
| 스타일 | Sub-01 토큰 + Sub-02 컴포넌트 스타일 재사용 |
| 인터랙션 | 바닐라 JS — 탭 전환, 체크박스 토글 |

## 핵심 요구 사항

### 1. 페이지 프레임 규칙

각 페이지 프로토타입은 **모바일 디바이스 프레임** 내에 배치한다.

**프레임 스타일:**
- 너비: 430px (고정)
- 높이: 932px (iPhone 15 Pro Max 기준) 또는 콘텐츠 높이
- 보더: 2px solid `--color-border-default`
- Border Radius: `--radius-lg` (12px)
- 배경: `--color-bg-base`
- 상단에 페이지 이름 라벨 표시

**레이아웃 규칙:**
- 프레임 내부는 실제 서비스와 동일한 레이아웃 적용
- BottomTabBar가 있는 페이지: 하단에 고정 배치
- 콘텐츠 영역: BottomTabBar 높이(76px = 56px + 20px safe area)만큼 하단 패딩

### 3. 탭 전환 인터랙션

BottomTabBar 탭 클릭으로 Life/Work/Settings 간 페이지 전환을 구현한다.

**동작:**
- Life 탭 클릭 → 2.2 Life 메인 페이지 표시
- Work 탭 클릭 → 2.3 Work 메인 페이지 표시
- Settings 탭 클릭 → 2.7 설정 페이지 표시

**구현 방식:**
- 각 워크스페이스 콘텐츠를 별도 `<div>`로 작성
- JS로 탭 클릭 시 `display: none` / `display: block` 전환
- 활성 탭의 아이콘/텍스트 색상 변경

### 4. 인터랙티브 데모 (모바일)

체크박스 토글, 탭 전환 등 모바일 프로토타입의 인터랙션 데모.

### 5. 데스크톱 프로토타입

모바일 프로토타입과 동일한 서비스를 데스크톱 레이아웃으로 구현한다. 별도 파일(`pages/page-prototypes-desktop.html`, `css/pages-desktop.css`)로 분리한다.

**프레임 규칙:**
- 너비: 1280px (고정)
- 사이드 네비게이션: 240px (좌측 고정)
- 콘텐츠 영역: 나머지 너비 (1040px)
- FAB 대신 "새 투두" 버튼을 사이드 네비게이션 또는 콘텐츠 상단에 배치

#### 5.1 메인 — Life

사이드 네비게이션(Life/Work/설정 메뉴) + 콘텐츠 영역(DateNavigator + TodoSection). DateNavigator는 주간 뷰 + 월간 달력 펼치기 구조를 그대로 적용한다.

#### 5.2 메인 — Work

5.1과 동일 구조, Work 샘플 데이터 사용.

#### 5.3 투두 생성 (센터 모달)

모바일의 바텀 시트 대신 화면 중앙에 모달로 투두 생성 폼을 표시한다. Epic 필드 제거, "등록일" 필드 포함.

#### 5.4 설정

사이드 네비게이션 + 설정 콘텐츠 영역. 프로필 카드, 메뉴 리스트, 로그아웃 버튼.

#### 5.5 인터랙티브 데모

데스크톱 레이아웃에서의 탭 전환, 체크박스 토글, 모달 열기/닫기 인터랙션.

## 구현 시 주의사항

1. **컴포넌트 재사용**: Sub-02에서 구현한 컴포넌트의 CSS 클래스를 그대로 사용한다. 페이지별로 스타일을 중복 정의하지 않는다
2. **프레임 격리**: 각 페이지 프레임 내부의 스타일이 프레임 외부에 영향을 주지 않도록 한다
3. **탭 전환**: 탭 전환은 메인 페이지 프레임 내에서만 동작한다. 프로토타입 목록의 개별 프레임 간 전환이 아니다
4. **샘플 데이터 일관성**: 모든 페이지에서 동일한 샘플 데이터(사용자, 카테고리, Epic, SubIssue)를 사용한다
5. **60-30-10 검증**: 페이지 프로토타입에서 컬러 비율이 적절한지 시각적으로 확인할 수 있어야 한다
   - 60% White/Gray (배경, 여백)
   - 30% Periwinkle + Lavender Gray (보더, 태그, 비활성)
   - 10% Purple 500 (CTA, 체크박스, FAB, 포커스)
