Dopamine Planner Design System

Dopamine Planner 서비스의 디자인 시스템 프로토타입입니다.
디자인 토큰, 아이콘, 컴포넌트를 한눈에 확인하고 검증할 수 있습니다.

1. 디자인 토큰
컬러 팔레트, 시맨틱 컬러, 컴포넌트 컬러, 타이포그래피, 간격, Border Radius, 모션 토큰
2. 아이콘 시스템
Lucide 기반 10개 아이콘 — 크기 변형(16/20/24px), 컬러 변형(Primary/Secondary/Brand)
3.1 Atoms
Button, Checkbox, Icon, Badge, Divider, Avatar — 기본 UI 단위 컴포넌트
3.2 Molecules
TodoItem, SectionHeader, DateNavigator, TabBarItem, FormField — 조합 컴포넌트
3.3 Organisms
TodoSection, BottomTabBar, TodoCreateSheet, CategoryList, EpicCard — 화면 단위 컴포넌트
4. 페이지 프로토타입
로그인, 메인(Life/Work), 투두 생성, 분류 관리, Epic 관리, 설정 — 7개 페이지 + 인터랙티브 데모
